# Rainy Days

A responsive multi-page website for an online jacket store, built with pure HTML and CSS.

[Live Site](https://kawalis98.github.io/html-css-tyrone-dhiin/) · [Figma Desktop](https://www.figma.com/proto/F29xwwiGOFf6Ttlld6V33Z/RAINY-DAYS-2.0?node-id=1-2&t=cypBC1AIQx8GoALv-1) · [Figma Mobile](https://www.figma.com/proto/gUdSd7Hqv7u9sLVSHS4kJ6/RAINY-DAYS-2.0-PHONE?node-id=0-1&t=9Pht9ZppT4b5YCo5-1)

## About

Rainy Days is a fully responsive e-commerce website designed and built from scratch. The project includes seven pages that work seamlessly across desktop, tablet, and mobile devices.

This was built as a course assignment with strict requirements: HTML and CSS only — no JavaScript, no CSS frameworks, no external libraries.

---

## Pages

| Page | File | Description |

## Tech Stack

- **HTML5** — Semantic elements, accessible markup
- **CSS3** — Custom properties, Grid, Flexbox, `:has()`, `:checked`
- **Google Fonts** — Inter typeface
- **No frameworks** — No Bootstrap, Tailwind, or JavaScript

---

## Features

- **Responsive design** — Adapts to desktop, tablet, and phone using media queries
- **CSS-only interactivity** — Mobile hamburger menu and cart badge using checkbox hacks
- **Semantic HTML** — `header`, `nav`, `main`, `section`, `aside`, `footer`
- **Accessibility** — Keyboard navigation, focus states, alt text, colour contrast
- **Performance** — Compressed images, lazy loading, preconnect hints
